# Downloads File Organizer

A lightweight Windows batch script that automatically organizes files in your Downloads folder into category-based subfolders.

## Features

- Automatically targets `%USERPROFILE%\Downloads`
- Creates category folders when they do not exist
- Moves files based on extension
- Leaves existing folders untouched
- Does not delete files
- Skips the organizer batch file itself

## Categories

- PDFs
- Documents
- Spreadsheets
- Presentations
- Images
- Videos
- Audio
- Archives
- Installers
- Code
- Text Files
- Data Files
- Design Files
- Other

## Usage

1. Download or clone this repository.
2. Double-click `Organize_Downloads.bat`.
3. The script organizes loose files inside your Downloads folder.

## Safety

The script moves files but does not delete them. Existing subfolders are left unchanged.

## Requirements

- Windows
- Command Prompt / Batch support
